Regras de Segurança do Firebase Firestore

Para ativar a gravação do painel no seu projeto semente-multiplicacao:

  1. Acesse o Console do Firebase (Aba Regras) ↗
  2. Cole o código abaixo e clique em Publicar (Publish):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /config/{configId} {
      allow read, write: if true;
    }
    match /events/{eventId} {
      allow read, write: if true;
    }
    match /prayer_requests/{requestId} {
      allow read, write: if true;
    }
  }
}

✨ Assim que publicar, todas as gravações do painel e do site se sincronizam instantaneamente em nuvem em qualquer dispositivo.
